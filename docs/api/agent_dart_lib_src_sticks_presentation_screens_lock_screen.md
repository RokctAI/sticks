Source file: `agent/dart/lib/src/sticks/presentation/screens/lock_screen.dart`

## Classes

### class `LockScreen`

The lock screen: how an ask or a result reaches the owner as a
notification. A preview of the push the backend will send.
Private by default: while locked it says who needs the owner and what
kind of thing it is (an ask or a message), never the work itself. The
owner can choose in Settings to see the work on the lock screen
([SticksPrefs.lockShowsWork]).
