# API Reference: connection_dot

Source file: `agent/dart/lib/src/sticks/presentation/connection_dot.dart`

## Classes

### class `ConnectionDot`

Whether the app can reach the server, without words: a still green dot
while it can, a red one that blinks while it cannot. Beside it, how many
messages wait to be sent, when any do. Screen readers hear it in words.
